# Listening and reading
- CPU - Central processing unit, fast execution, capable of execute pretty all the instructions, may be parallel on modern chips
- GPU - Graphical processing unit, handles thousands of small calculations at the same time. It is used for graphics, video, gaming and AI training.
- TPU - Tensor processing unit, a chip designed by Google for the maths used in machine learning (tensors). It is used to train and run neural networks quickly.
- NPU - Neural processing unit, a low-power chip built into laptops and phones. It runs AI tasks such as face recognition, background blur and voice assistants.
- LPU - Language processing unit,  a chip designed to run large language models (chatbots) very fast.
- IPU - Intelligence processing unit, a chip designed for AI workloads that handles many tasks in parallel.
- DPU - Data processing unit, manages data movement, networking and security in servers, so the CPU is free for other work.
- QPU - Quantum processing unit, a processor that uses quantum bits (qubits). It is used for very specific problems, such as chemistry and optimization.

# Le circuit économique
## 1 - Les agents économiques
Classification INSEE
- Les ménages
- Entreprises individuelles (n'ont pas le status de société) :
    - Commerçants
    - Artisans
    - Agriculteurs
    - Professions libérales
- Entreprises du secteur privé (ont un status juridique) : 
    - Sociétés non financières
    - Sociétés financières (assurances, banques...)
- Administrations privées : 
    - syndicats
    - associations
    - Partis politiques
- Administrations publiques : 
    - Collectivités territoriales
    - Administrations d'état : 
        - Ministères
        - ODAC (Organisme Dépendant des Administrations Centrales -> ex : université)
        - URSSAF
- Reste du monde
